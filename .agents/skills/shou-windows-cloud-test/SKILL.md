# Shou Windows 云端测试

CLI/API 负责资源、源码同步、构建测试和证据导出；Computer Use 负责本地无影客户端、真实窗口交互与截图。先读取 [快速驱动](references/quick-drive.md)，复用已保存实例与磁盘工具缓存，避免重复购买、下载 SDK 或重新询问账号密码。

本技能仅服务包含本文件的 Shou 仓库；不安装为全局技能，不修改其他项目。界面基线先读仓库[原生界面设计](../../../docs/zh-CN/engineering/interface-design.md)与[跨端对齐](../../../SYNC.md)。新工作台布局取代旧侧栏基线；历史 Mac 紧凑字号、截图或此前“1:1”要求不能自动覆盖用户本次的新设计。共享资源生成不代表 Windows 导航或页面已经完成改造。

**节省测试费用的默认顺序**：云电脑在本地开发、UI 对齐、文档与 Mac 纯 .NET 验证期间保持 `StopCharging` 关机；先完成可在本机完成的工作，准备好同步包和 Windows 验收步骤后，再开机进行集中构建、测试与截图。不要让云电脑空转等待改代码。生命周期始终以本次最新要求为准；用户选择保留一天时，将截止时间写入技能外的 `active-desktop.json.retain_until`，不能将旧会话的保留偏好当作本次释放指令的例外。

## 配置与授权

- 读取仓库 `AGENTS.md`、Windows 原生实施方案、`SYNC.md` 和对应安全合同。记录本次提交及工作区状态。
- 默认配置见 [references/default-template.json](references/default-template.json)。本地账号引用在 `~/.local/share/shou-cloud-test/account.json`；密码仅在 macOS 钥匙串中，不能写入 Skill、报告、命令输出或源码。CLI 优先复用 OAuth profile，不为便利创建 AccessKey。
- 用户偏好：按量计费，总预算默认 ¥5；优先复用 `~/.local/share/shou-cloud-test/active-desktop.json`，调用 API 核对存活、账号、办公网络和状态后再驱动。会话中最新的保留／释放要求优先；用户要求关机保留时使用 `StopCharging`，不能沿用旧的销毁指令。保留时磁盘持续收费，说明小时／天费用及预算可覆盖期限；超出预算的长期保留不能由技能自行授权。
- 每次恢复任务先读 `retain_until` 和预算；到期应按既有授权处理资源或向用户说明待处理状态，不能静默续留。没有实际配置计时执行器时，不声称已安排自动到期释放。
- 使用当前会话已有授权，不重复询问已授权的购买、协议、临时夹具、关机或释放动作。Skill 与模板本身不授权下一次新购买、新权限或任意资源删除。
- 新购前重新核对实际报价、磁盘、镜像、网络和可用规格，历史单价只能参考。按所有收费项及本次累计支出计算截止时间并预留至少 20 分钟导出与收尾。记录本次实例 ID；不复用已释放的历史 ID，不选择包年包月、自动续费或未经要求的付费带宽、快照。
- 优先复用 `shou-test` 和既有办公网络。无需为本流程提升到最高权限；权限不足时准确报告。新账号密码由安全随机源生成并存入钥匙串，不让用户复制密码参与常规流程。

## 执行与留证

具体已验证的 CLI 版本、RPC 参数和原生命令见 [references/aliyun-cli.md](references/aliyun-cli.md)。先用当前 API/help 发现购买和报价参数，不把历史结果当作动态产品事实。

- 创建后立即建立本次资源清单、开始时间、预算截止时间和异常释放路径。GUI 和当前用户注册表/MSIX/启动项检查在已登录的 `shou-test` 会话执行；SYSTEM 结果不能替代用户会话。
- 固定源码提交和仓库要求的 SDK。构建缓存与测试产物放 Windows 本地盘。ZIP 源码缺少 Git provenance 时保留这一事实，不伪造 provenance 来启用原生专项。
- 工作树有未提交修改时必须同步 overlay 和逐文件 SHA256，不能只构建 GitHub HEAD。使用 `scripts/wuying.py overlay/upload/download/run`，分块传输与导出自动校验长度、截断和摘要；远程脚本退出码非零即失败，即便 API 总体状态是 Success。
- 测试脚本必须绑定本机期望的 overlay／manifest 摘要，并核对实际解压文件名；仅校验云端包内自己的 manifest 会把误用的旧包也判为正确。变更轮次标签不能代替包身份；先核对本机期望文件摘要，再启动原生专项。
- 运行仓库 Windows 测试、x64 自包含构建及发布启动/正常关闭检查。根据本次范围另行运行原生专项；Mac 纯 .NET、引用编译、x64、ARM64、签名、安装、更新及 UI 验收分别取证。
- 功能排错先读仓库 [Windows 日志与测试](../../../docs/zh-CN/engineering/windows-testing.md)。交互用户会话使用 `powershell.exe -NoProfile -STA -File scripts/windows/test-desktop-e2e.ps1` 驱动真实控件；通过 `collect-diagnostics.ps1` 导出结构化日志、TRX 实际计数、缺失证据及产物摘要。E2E 超时／缺少控件／页面失败要保留失败回执，不能改成仅窗口启动检查。脚本源码与语法通过不能记作原生 E2E 通过。
- 优先导出逐步 `checkpoint.json`，再导出最终 `verification.json`；前者明确 `verification_complete=false`，不能当作最终验收。普通用户会话、提升权限进程、原生选择器的控件 ID／模式分别留证；默认字段 ID 不匹配时先导出实际控件树，不注入页面结果或略过旅程。
- 删除与系统变更只使用本次生成的临时夹具，遵守仓库专项的显式 opt-in 和来源限制。保留精确范围确认合同；测试通过也不自动打开公开清理、卸载或启动控制门禁。
- 实际检查智能清理、空间分析及下钻、应用、启动项、隐私、规则、历史等已支持页面。保留原始全屏截图；可另存窗口裁剪图。记录空、失败、部分覆盖等实际状态，不能把页面能打开记成完整功能通过。
- 将报告、TRX、日志、系统/架构/工具链、能力 JSON、夹具摘要、截图及退出码分批导出本地。分块导出时逐块落盘，验证输出未截断、长度及 SHA256；有损恢复必须明确哪些文件完整。

## 关机保留、释放与交付

- **关机保留**：导出主要证据、关闭测试应用，使用 `StopDesktops` + `StoppedMode=StopCharging`，轮询到 `Stopped`。这会回收计算资源、停止 CPU／内存费用，保留磁盘、SDK、NuGet 缓存及产物；库存不足时下次开机可能暂时失败。不能使用仍收计算费的 `KeepCharging`，也不能把断开客户端当作关机。磁盘及已有收费网络独立计费，实际规则见 [CLI 与计费参考](references/aliyun-cli.md#关机保留与计费)。
- **释放**：仅用户选择或已有会话授权适用时，导出主要证据、关闭应用、释放本次精确实例、轮询 API 确认实例不存在。遇到阻塞或预算截止，按本次选定策略及时关机或释放；短暂读取错误可有限重试，不为追求完整日志让实例持续运行，不重购实例补证。
- 释放请求成功不等于释放完成。保存回执与最终空实例查询，并检查本次附属收费网络、快照等资源。只处理本次资源，不删除留作复用的账号、办公网络或其他实例。
- 最终报告分别列出通过、失败、跳过和未验证范围；内嵌真实 Windows 截图，附证据路径、最终关机／释放状态及费用估算。关机要明确存储仍收费；账单尚未入账时注明延迟，不能把空账单当作免费。
- 用户要求与 macOS **1:1 对齐**时，以本机 Mac 实际截图和视图源码作为尺寸、颜色、图标、文字、分组和状态布局基准；同内容尺寸、同状态、同夹具逐页核对，保留对比图。默认 Fluent 控件、只改导航或构建通过均不能记作复刻完成。按原生 WinUI 3 实现产品布局，保留 Windows 系统标题按钮、键盘与可访问性；平台能力差异明确说明，未支持的 AI／变更能力不能假造。
