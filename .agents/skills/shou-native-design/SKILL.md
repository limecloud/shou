# Shou 原生界面设计

作用范围是包含本文件的 Shou 仓库。保留在 `.agents/skills/` 中，不安装到全局目录，不替其他项目建立规范。

先读[原生界面设计](../../../docs/zh-CN/engineering/interface-design.md)，再读任务涉及的产品合同和 [SYNC.md](../../../SYNC.md)。应用与项目的组织以[应用与项目](../../../docs/zh-CN/product/apps-and-projects.md)为准；需要理解参考时再读[设计参考分析](../../../docs/zh-CN/engineering/workspace-design-review.md)。这些文档拥有事实，本技能不复制整套尺寸和页面规范。

## 设计决策

- 当前方向是顶部分组导航、开阔内容区、全宽对象列表、行内明细和稳定的选择底栏。旧侧栏、密集小字和历史截图是已替换的基线，不能作为必须遵守的视觉限制。用户的新方向优先。
- 渐变覆盖整个窗口底层，由 `WorkspaceBackdrop` 统一贯穿导航、留白和内容区；不能只给插画或首页局部面板加渐变。明暗外观分别配色，高对比度减少光晕。结果面板保留可读的浅／深表面，不用大色块遮住整个窗口背景。
- 每个主／次级功能页都有对应的原创插画：扫描前用 `WorkspaceStartPage`，规则、历史、设置可用紧凑插画标题；空间、大文件、应用、启动项和隐私的结果直接呈现工具栏与数据，空结果用 `WorkspaceEmptyState`。不能退回单个系统图标加居中文字的空页。图形可编辑源保留在本仓库的 `WorkspaceIllustration.swift` 和 `WorkspacePageArtwork.swift`；不把位图生成接口当作必需依赖。插画不显示虚构的扫描数字、清理资格或进度；减少动态效果时禁用悬停位移，默认页不播放无限循环动画。
- 实用性优先：大插画只在初始页展示；结果／扫描状态采用 48 pt 紧凑主导航，去掉重复大标题与宣传留白。最小窗口中列表、筛选和底部操作必须同时可用，不通过缩小关键文本腾空间。
- 借鉴参考的层级、留白、渐进展开和任务反馈；使用 Shou 的品牌、图标和视觉语言。不复制参考产品的标识、行星素材、插画、逐像素布局或宣传数据。
- 按用户对象和任务组织功能：应用、项目产物、共享缓存。规则作为共用匹配事实源；GitHub 来源、本地 Git 状态和目录名称都不能证明可删除。未经实现的更新、监控或项目整体删除，不做可操作空壳。
- 布局必须覆盖真实空、加载、部分、可选、确认、执行、失败与完成状态。聚焦行与勾选范围分开；路径、重建代价和手动审阅原因靠近选择项。

## 实现与验收

macOS 使用 SwiftUI/AppKit，Windows 使用 WinUI 3。Core 负责归属、匹配、资格和删除范围；UI 只呈现事实和选择。共享设计值只改 `assets/design/tokens.json`，文案只改 String Catalog，再运行生成器及 `--check`。不手改生成的 Swift／XAML／文案副本。修改插画或 token 后，在 Mac 执行 `python3 scripts/workspace_artwork.py`，再生成 Windows 资源；`--check` 核对同源透明 PNG 与源文件摘要。

修改受影响的中英文设计／产品文档，移除与新布局矛盾的现行要求；历史验收保留日期和旧基线标记，不重写为本次证据。按仓库规范构建与检查，在真实应用中验证顶部导航、展开、勾选、底栏容量、确认取消、最小窗口及明暗外观。删除回归只用生成夹具；真实个人目录只做只读选择和取消。已有本地覆盖安装授权可以沿用。

验收记录注明实际平台、构建与截图状态。Windows 资源生成、Mac 上的 .NET 检查和真实 WinUI 渲染分别记录；远程 Windows 验收才使用本仓库云测试技能，不为纯设计文档工作启动云电脑。
