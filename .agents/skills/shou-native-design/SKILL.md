# Shou 原生界面设计

作用范围是包含本文件的 Shou 仓库。保留在 `.agents/skills/` 中，不安装到全局目录，不替其他项目建立规范。

先读[原生界面设计](../../../docs/zh-CN/engineering/interface-design.md)，再读任务涉及的产品合同和 [SYNC.md](../../../SYNC.md)。应用与项目的组织以[应用与项目](../../../docs/zh-CN/product/apps-and-projects.md)为准；需要理解参考时再读[设计参考分析](../../../docs/zh-CN/engineering/workspace-design-review.md)。这些文档拥有事实，本技能不复制整套尺寸和页面规范。

## 设计决策

- 先按[界面风格基线](../../../docs/zh-CN/engineering/interface-design.md#界面风格基线)审阅受影响的既有页面和新页面：无中点分隔、重复说明或装饰眉题；文案面向用户，必要后果留在既有审阅处。自定义色只用 Radix 语义 token，工作页优先 12／14／22 三档文字；0.5 边线、光学对齐、嵌套同心圆角，减少阴影和动画，必要过渡 ease-out／250 ms。不新增卡片左侧装饰色线、重复确认或额外选择。
- 应用名称只在原生标题栏出现一次，内容主导航不重复品牌区；主次导航从内容左边距对齐，操作记录和设置靠右。
- 应用标识以 `assets/brand/README.md` 为准：原创笑脸收纳盒，Mac ICNS 与 Windows ICO 由同一位图母版生成；首页主视觉展示透明吉祥物，设置“关于”展示版本旁图标，修改后检查小尺寸与实际包内资源。结果列表不增加常驻吉祥物；各页主题使用同一收纳盒、材质、配色与光线的共享插画族。
- 当前方向是顶部分组导航、开阔内容区、全宽对象列表、行内明细和稳定的选择底栏。旧侧栏、密集小字和历史截图是已替换的基线，不能作为必须遵守的视觉限制。用户的新方向优先。开发者工具与 AI 工作台按当前用户要求使用模块内部分类列表＋常驻右侧来源版本表；这是工具页的任务布局，不改变顶部主导航。
- 渐变覆盖整个窗口底层，由 `WorkspaceBackdrop` 统一贯穿导航、留白和内容区；不能只给插画或首页局部面板加渐变。明暗外观分别配色，高对比度减少光晕。结果面板保留可读的浅／深表面，不用大色块遮住整个窗口背景。
- 每个主／次级功能页都有对应的原创插画：扫描前用 `WorkspaceStartPage`，规则、历史、设置可用紧凑插画标题；空间、大文件、应用、启动项和隐私的结果直接呈现工具栏与数据，空结果用 `WorkspaceEmptyState`。不能退回单个系统图标加居中文字的空页。插画母版、提示词和生成记录保存在 `assets/design/illustrations/`，由原生视图加载同源透明 PNG；新图使用用户授权的 GPT Image 流程，以本仓库标识为参考。构建只做离线导出，不请求生图接口，不保存密钥。插画不显示虚构的扫描数字、清理资格或进度；减少动态效果时禁用悬停位移，默认页不播放无限循环动画。
- 实用性优先：大插画只在初始页展示；结果／扫描状态采用 48 pt 紧凑主导航，去掉重复大标题与宣传留白。最小窗口中列表、筛选和底部操作必须同时可用，不通过缩小关键文本腾空间。
- 默认窗口采用共享的 1280 × 800 逻辑尺寸；按可用高度和宽度调整首页插画、留白与横向入口卡片，保证首屏任务入口完整。检查透明轮廓毛刺和实际缩放效果；平滑 alpha、保留 RGB 材质，不能用整图模糊掩盖锯齿。
- 借鉴参考的层级、留白、渐进展开和任务反馈；使用 Shou 的品牌、图标和视觉语言。不复制参考产品的标识、行星素材、插画、逐像素布局或宣传数据。
- 按用户对象和任务组织功能：应用、项目产物、共享缓存。规则作为共用匹配事实源；GitHub 来源、本地 Git 状态和目录名称都不能证明可删除。未经实现的更新、监控或项目整体删除，不做可操作空壳。
- 包管理器升级沿用应用任务：Mac 使用应用／Homebrew／mise 来源切换，Windows 使用已核实的系统 WinGet 来源。列表对比当前与目标版本，单项／批量选择后只确认一次，强调色升级动作与红色永久删除分开；停止、执行前受阻、未开始和结果不确定必须准确呈现。不得根据 Cask 名称推断某个具体应用副本的安装归属，也不把包管理器返回成功视为安装核验成功。依据[升级合同](../../../docs/zh-CN/product/application-updates.md)实现，真实个人软件不作为升级回归夹具。
- Shou 自身更新从设置“关于”进入，与其他应用的更新发现分开；原生窗口显示版本、说明和实际可用动作。按[发布合同](../../../docs/zh-CN/engineering/releasing.md#桌面更新行为)区分 Mac 签名安装与 Windows 便携版手动下载，不把下载或关闭窗口描述成已安装或稍后自动提醒。
- “工具”下分开开发者工具与 AI 工作台，复用[工具管理合同](../../../docs/zh-CN/product/developer-tools.md)。两页共用布局、来源胶囊筛选和版本／路径表；唯一已核实服务可在工具行直接启停，多服务在右侧按来源展示，未知不画假 OFF，未接入不开空壳开关。默认首个入口为我的工作台，仅显示明确选入的软件；添加工具融合目录、已安装状态和来源，不设独立已安装 tab。添加页胶囊控制成员选择，工作台胶囊控制确切服务；移出不停止、不卸载。已选服务批量后台核验，不能依赖逐个点开。已有安装显示来源、实际路径、多副本和未核实状态，不以文件存在冒充正常运行或卸载权限。目录收录不等于全部服务已实现；来源未接入和 Windows 安装器门禁必须如实呈现，不能增加可点击空壳。安装用强调色，卸载用红色，在原生详情中只确认当前来源的一次计划。AI 软件配置与 Shou 自身规则调查分开，见 [AI 工作台](../../../docs/zh-CN/product/ai-workbench.md)。
- 智能清理、开发项目、应用组件、空间分析与大文件清理统一为列表内审阅和勾选、底部红色永久删除主按钮，点击即确认本次冻结范围，校验后执行，不叠加第二次弹窗；手动整目录影响、个人数据同意和 Windows 安装身份在行内呈现，系统认证及公开变更门禁保持原合同。
- 工具工作先读[全量能力与领域边界](../../../docs/zh-CN/engineering/developer-tool-capability-map.md)，再按[领域目录与职责](../../../docs/zh-CN/engineering/developer-tool-adapters.md#工具领域的源码组织)实现。已有软件目录不限制目标范围；不能只围绕 MySQL、Nginx、Redis、PostgreSQL、MongoDB 五种适配。复核参考时从实际根注册、嵌套管理器、内部工具和专属任务追踪后端，记录当前提交及增量；不把目录存在当功能完成。视图按真实能力组装，区分安装、实例、项目、容器、站点证书、网络、任务与 AI；语言项目开关不能套用解释器服务，companion 独立管理。共用身份／文件／状态机复用，软件专属策略留在本软件目录，不为未实现软件建立空文件夹或全能基类。
- 软件任务必须逐项对照对应模块源码与实际能力，不以公共来源表代替专属管理。MySQL 使用[专属合同](../../../docs/zh-CN/product/mysql-administration.md)，区分安装、运行实例、数据库、User/Host、配置及错误／慢日志；新增功能先做独立实例／真实引擎验证，再做实际界面验收。维护态改密码、独立实例初始化、账号授权和包安装分别实现，不能共用通用命令入口或以目录收录宣称完成。
- MySQL 实例组以每行自身为上下文，不重复显示占用高度的全局实例选择面板；创建表单渐进展开并明确选择安装版本。组行直接显示状态、PID、胶囊和重启，管理菜单按内容收紧宽度。登记变更独立审阅并验证已停止；配置的缩写、别名及路径范围由专属合同核实，不能只检查界面显示的端口。移除登记保留数据，不描述为清理或释放空间。
- 工具页先显示结构和会话结果，本地元数据先于管理器查询；安装来源逐步合并，服务按当前工具读取并合并重复请求。只读刷新不进入全局 busy，不阻止搜索和页面切换；旧状态保留检查时间，不能授予变更。内容全宽不代表窗口全屏，默认尺寸与用户调整分别保留。
- 布局必须覆盖真实空、加载、部分、可选、确认、执行、失败与完成状态。聚焦行与勾选范围分开；路径、重建代价和手动审阅原因靠近选择项。

## 实现与验收

macOS 使用 SwiftUI/AppKit，Windows 使用 WinUI 3。Core 负责归属、匹配、资格和删除范围；UI 只呈现事实和选择。共享设计值只改 `assets/design/tokens.json`，文案只改 String Catalog，再运行生成器及 `--check`。不手改生成的 Swift／XAML／文案副本。修改插画母版后，在 Mac 执行 `python3 scripts/workspace_artwork.py`，再生成 Windows 资源；`--check` 核对母版、提示词和同源透明 PNG 摘要。官网素材通过 `scripts/export-web-brand.py` 从同一标识、token 和插画导出；保留 PNG、WebP、横版浅深字标与 favicon，并用 `--check` 检查，不创建官网功能空壳。

修改受影响的中英文设计／产品文档，移除与新布局矛盾的现行要求；历史验收保留日期和旧基线标记，不重写为本次证据。按仓库规范构建与检查，在真实应用中验证顶部导航、展开、勾选、底栏容量、确认取消、最小窗口及明暗外观。删除回归只用生成夹具；真实个人目录只做只读选择和取消。已有本地覆盖安装授权可以沿用。

验收记录注明实际平台、构建与截图状态。Windows 资源生成、Mac 上的 .NET 检查和真实 WinUI 渲染分别记录；远程 Windows 验收才使用本仓库云测试技能，不为纯设计文档工作启动云电脑。
