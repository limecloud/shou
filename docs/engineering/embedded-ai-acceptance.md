## 3. Execution requirements

Cover local-sufficient, decision-sufficient, necessary escalation, missing intent, invalid responses, exhausted budgets, revocation and offline rules. Assert actual requests per service; final suggestions do not prove routing. Use generated directories for independent drafts, previews, enablement, fresh scans, explicit confirmation, receipts and recovery. Windows is planned under the [native implementation plan](windows-native-plan.md).
