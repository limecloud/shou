# 原生界面设计

[English](../../engineering/interface-design.md) | 简体中文

这是 Shou 当前的界面事实源。2026-10-25 的新工作台设计取代旧侧栏与紧凑字号基线；历史截图、旧版本的逐页对齐记录不再约束新布局。功能、安全和平台边界继续由所属合同定义。

## 设计方向

以开阔、清晰、可检查为目标。借鉴参考演示中的导航层级、全宽列表、行内展开和稳定操作区，形成 Shou 自己的冷中性底色与青绿色强调。保留本产品品牌和原生系统行为，不使用对方标识、行星素材或逐像素复刻。参考的功能与设计证据见[视频分析](workspace-design-review.md)。

减少常驻导航列和互相竞争的摘要面板，把宽度留给名称、路径和容量。标题、对象行和明细形成明确层级；不要通过同时放大所有控件或堆叠装饰卡片制造“大气”。仅在具有独立选择或任务作用时使用面板。

## 导航与页面结构

主导航位于顶部：清理、应用与项目、空间分析、规则。操作记录和设置使用右侧固定入口。次级导航放在主导航下面：

| 主导航 | 次级任务 |
| --- | --- |
| 清理 | 智能清理、隐私 |
| 应用与项目 | 应用、开发项目、启动项；应用残留从应用页进入 |
| 空间分析 | 空间分析、大文件 |
| 规则 | 内置与个人规则、扫描位置与排除设置 |

原生标题栏承载窗口控制和上下文工具；初始页说明用途，结果页直接呈现工具栏与数据，操作进度和完成页使用自己的聚焦结构。结果占据剩余高度，批量选择动作固定在页面底部。不要再增加重复的版本栏、容量栏或始终空白的状态栏。底层操作状态仍提供可访问名称。

当前共享 token 的初始窗口为 1440 × 875 pt，最小 960 × 680 pt；已保存的窗口尺寸仍由系统恢复。主导航和页面内容需在最小窗口、英文和长路径下保持可用；必要时重排筛选区，不能靠压缩关键文本解决。

## 清理工作台

未扫描的默认页采用横向主视觉：左侧为两行标题、用途、渐变扫描按钮和“先扫描、再确认”的说明；右侧为原创的半透明文件夹、层叠文件和浮动应用小卡插画。渐变是整个窗口的背景，由 `WorkspaceBackdrop` 贯穿主导航、次级导航、留白与内容区，从柔和青绿过渡到冰蓝；不再限制在插画或局部圆角面板中。深色外观使用独立的低亮度配色，高对比度关闭装饰光晕。下方三个小插画入口分别进入应用与项目、空间分析和清理规则，均连接已有页面；可选 AI 入口放在次级辅助行。

插画源为 [WorkspaceIllustration.swift](../../../apps/macos/Sources/WorkspaceIllustration.swift)，首页组装为 [CleanupWelcomeView.swift](../../../apps/macos/Sources/CleanupWelcomeView.swift)。图形由原生矢量和渐变绘制，支持任意缩放，不依赖网络图片或外部素材。颜色和提取的版式值仍来自共享 token；路径坐标属于插画可编辑源。装饰空间块不表示实际容量或清理资格，辅助功能忽略装饰层。首页不播放无限循环动画，任务入口的悬停位移遵守减少动态效果。内容不足以容纳时允许纵向滚动，不裁切扫描按钮。

其他功能页使用 [WorkspacePageArtwork.swift](../../../apps/macos/Sources/WorkspacePageArtwork.swift) 的同材质独立构图及 `WorkspaceStartPage`。应用与启动项首次进入先展示用途与只读检查按钮，用户启动后显示真实进度与结果；已有结果在切页后保留，不重新插入介绍页。空间与大文件继续保留位置选择，项目复用统一扫描，隐私首页保留时间范围、永久删除影响及支持范围。规则、设置和已有历史直接显示内容，以紧凑插画标题统一视觉；无历史和筛选空结果也有对应插画。任何装饰都不能成为额外的确认授权。

| 页面 | 插画主题 |
| --- | --- |
| 应用 | 层叠应用面板与图标格 |
| 开发项目 | 终端、代码和构建包 |
| 空间分析 | 空间块与磁盘 |
| 大文件 | 文档、媒体与放大镜 |
| 隐私 | 浏览器文档、盾牌与锁 |
| 启动项 | 电源与启动箭头 |
| 规则／设置 | 分层调节面板及勾选／齿轮 |
| 历史 | 操作回执与时钟 |

实用性优先：空间、大文件、应用、启动项和隐私已有结果时不再放大插画或重复页面标题，项目结果仅保留紧凑说明。筛选、列表／树图与底部操作优先使用剩余高度；最小窗口也必须能浏览和操作。

扫描结果先呈现类别、位置数量和容量估算。类别全宽排列，展开后展示规则／软件，再展开到具体路径；搜索沿用同一组对象。每级复选框都使用当前三态选择，不因为展开或聚焦而改变勾选。

底栏集中展示已选数量、当前选择容量和一个明确的永久清理主操作。可选废纸篓动作放入次级菜单。手动审阅项目可显式勾选，但不得混入自动推荐；确认前重新完整计量并展示整目录影响。受保护位置、排除、所有者和当前清单检查仍由 Core 决定。

空间分析与大文件的列表、树图、导航、选择及直接删除继续使用[空间合同](../product/space-analysis.md)。图形面积表示占用，不能暗示全部可以清理。

## 应用与项目

应用列表采用舒展的对象行：应用图标、名称与版本、状态、容量、最近使用，展开显示关联组件及具体路径。个人数据同意靠近组件选择，归属不明确和共享数据保持保留或不可用状态。应用卸载沿用其独立确认合同。

更新检查放在应用行内明细，说明单款查询的网络来源，由用户点击后才开始；展示版本、观察时间和未知原因，官方入口由用户主动打开。复用列表及其展开状态，不添加更新顶级导航。来源与版本限制见[应用更新发现](../product/application-updates.md)。

开发项目以观察到的项目标记归组构建产物与依赖，未识别项目时明确按扫描位置归组。容量仅描述命中的清理项目，不冒充整个源码项目大小。智能清理和项目页复用相同候选身份、规则与选择；项目页操作只准备本页项目范围。具体边界见[应用与项目](../product/apps-and-projects.md)。

## 视觉资源

所有提取的设计值维护在 `assets/design/tokens.json`。macOS 初始页使用 72 pt 主导航，结果／扫描和功能列表使用 48 pt 紧凑主导航；Windows 当前使用 48 pt 主导航。规则、历史、设置标题为 22 pt，其余结果不重复大标题、14 pt 对象正文、40 pt 图标与 28 pt 页面内边距；行内留白和摘要数字同样由资源生成。细节、辅助状态和路径保持足够可读，不能恢复旧版 10 pt 的关键说明密度。

用真实明暗外观检查文本、强调色、选择和焦点。颜色表达状态时必须配文字或图标。图表色板是数据编码，不作为各页面的大面积装饰。系统高对比度、减少动态效果、键盘和辅助功能优先于装饰效果。

执行 `python3 scripts/generate-windows-resources.py` 生成 Windows XAML 与 `ShouDesign.generated.swift`，再运行 `--check`；不手改副本。插画在 Mac 通过 `python3 scripts/workspace_artwork.py` 从可编辑源导出十张透明 PNG 与摘要清单；Windows 生成器复制到 `Generated/Illustrations`。源或 token 变化时先重新导出再生成，两个脚本的 `--check` 分别核验来源和副本；Mac 继续使用同源矢量。文案唯一来源为 String Catalog。Schema 的字段、摘要与拒绝规则由生成器及其测试维护。

## 实现与验收状态

macOS 已构建并覆盖安装新工作台，实际验证范围见 [SYNC.md](../../../SYNC.md)。Windows 源码已替换顶部分组导航、全窗渐变、同源插画初始页和全宽清理列表；项目页按共享类别限制选择范围，尚无 macOS 的项目标记归组和手动审阅等价实现。2026-10-26 在 Windows 11 x64 云电脑实际构建 WinUI，并通过 Computer Use 检查初始页、只读扫描、展开、选择、小窗口及明暗切换；设置与隐私行模板的 Double／GridLength 资源类型错误已修复，代码生成控件使用动态主题资源。截图和失败回执见 [Windows 测试记录](windows-testing.md#2026-10-26-windows-11-云端验收)。公开变更、完整桌面 E2E、ARM64 运行、签名安装及逐页 macOS 等价验收仍未通过。

使用生成数据覆盖空、加载、部分覆盖、就绪、确认、执行、停止、失败和完成。验证顶部与次级导航、展开与勾选、筛选后选择、底栏容量、取消确认、最小窗口和明暗外观。只用生成夹具验证删除；真实个人数据只允许只读检查及取消。构建、状态测试和资源检查不能代替真实 UI 或签名安装证据。
