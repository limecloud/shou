# 原生界面设计

[English](../../engineering/interface-design.md) | 简体中文

## 信息层级

围绕用户任务组织界面：扫描、检查、选择、清理。导航、页标题和主要动作位置稳定。精确路径、风险、覆盖缺口与重建后果靠近受影响的选择项。普通用户流程不展示内部模块名和计划实现细节。

主要入口包括智能清理、空间分析、大文件、应用、启动项、隐私、个人规则、历史和设置。仅显示已支持能力。Windows 各入口属于规划，必须具备相应实现和验收。

## 选择与结果

列表、空间图和分类视图使用同一份选择状态。父子项去重，统一展示分配容量估算。路径保留开头和文件名，中间只出现一次省略，悬停与辅助功能提供完整值。

桌面默认永久清理，执行前确认当前精确选择、不可逆后果及独立同意的个人数据。可选废纸篓或回收站使用明确动作名称。结果区分完成、跳过、失败、取消和未知；移入废纸篓不描述为已经释放磁盘空间。

## 原生行为

macOS 使用 SwiftUI/AppKit，Windows 使用 WinUI 3。共享颜色、字号、间距、圆角与文案通过资源生成，同时遵循平台键盘、焦点、对话框、窗口和可访问性习惯。验证明暗、高对比度、减少动效、长翻译和 DPI 缩放。页面状态可在本平台内独立测试，UI 框架类型只留在应用层。

## 验证

使用生成数据检查空、加载、部分、就绪、确认、执行、停止中、失败与完成状态。检查返回来源页、重新扫描、选择保持、确认取消和辅助标签。真实 UI 证据与状态测试分别记录。见[流程](../architecture/workflows-and-sequences.md)和[验收](acceptance-and-testing.md)。
