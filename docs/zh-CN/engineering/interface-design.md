# 原生界面设计

[English](../../engineering/interface-design.md) | 简体中文

这是 Shou 当前的界面事实源。2026-10-25 的新工作台设计取代旧侧栏与紧凑字号基线；历史截图、旧版本的逐页对齐记录不再约束新布局。功能、安全和平台边界继续由所属合同定义。

## 设计方向

以开阔、清晰、可检查为目标。借鉴参考演示中的导航层级、全宽列表、行内展开和稳定操作区，形成 Shou 自己的冷中性底色与青绿色强调。保留本产品品牌和原生系统行为，不使用对方标识、行星素材或逐像素复刻。参考的功能与设计证据见[视频分析](workspace-design-review.md)。

减少常驻导航列和互相竞争的摘要面板，把宽度留给名称、路径和容量。标题、对象行和明细形成明确层级；不要通过同时放大所有控件或堆叠装饰卡片制造“大气”。仅在具有独立选择或任务作用时使用面板。

## 导航与页面结构

主导航仅保留清理、应用、空间分析、监控，面向日常电脑管理。右侧辅助入口为工具箱、操作记录、设置；不把专业服务管理放在主任务中。

| 入口 | 次级任务 |
| --- | --- |
| 清理 | 智能清理、隐私；清理选项进入扫描位置、清理规则、项目清理和可选 AI 调查 |
| 应用 | 应用、软件更新、启动项；应用残留从应用页进入 |
| 空间分析 | 空间分析、大文件 |
| 工具箱 | 先展示 AI 工作台、开发者工具两个模块，选入后才加载对应软件盘点 |

项目清理和规则页归属清理，进入后显示当前上下文并可返回智能清理；它们不占默认页签。规则是智能清理的配置，项目产物使用同一扫描和选择事实源。工具箱内提供返回入口与模块切换，保留各模块内部工作台、来源和专属任务。

应用名称仅在原生标题栏出现一次；内容区不重复放图标与品牌名。主导航与次级导航统一从内容左边距起排，工具箱、操作记录和设置靠右。原生标题栏承载窗口控制和上下文工具；初始页说明用途，结果页直接呈现工具栏与数据，操作进度和完成页使用自己的聚焦结构。结果占据剩余高度，批量选择动作固定在页面底部。不要再增加重复的版本栏、容量栏或始终空白的状态栏。底层操作状态仍提供可访问名称。

当前共享 token 的初始窗口为 1280 × 800 逻辑单位（16:10），Mac 最小内容尺寸 960 × 600 pt，确保加上标题栏后在 1280 × 800 屏幕上不被下方 Dock 遮挡；已保存的窗口尺寸仍由系统恢复。Mac 与 Windows 均按可用工作区（visibleFrame / WorkArea）与 DPI 限制初始尺寸及位置，两端按页面可用高度自适应，不要求用户维持固定比例。主导航和页面内容需在最小窗口、英文和长路径下保持可用；必要时重排筛选区，不能靠压缩关键文本解决。

首页在页面高度不足 620 或宽度不足 1100 时，收紧标题间距、插画尺寸与外边距；三个入口使用左文右图的紧凑横向卡片。优先完整展示扫描按钮、三个入口和清理选项，极小窗口或长文案仍可纵向滚动。插画的透明轮廓先平滑再重建抗锯齿边缘，RGB 材质保持原样，Mac 使用高质量插值。

## 清理工作台

未扫描的默认页采用横向主视觉：左侧为两行标题、用途、渐变扫描按钮和“先扫描、再确认”的说明；右侧展示原创的青绿笑脸收纳盒吉祥物，透明背景直接融入窗口。渐变是整个窗口的背景，由 `WorkspaceBackdrop` 贯穿主导航、次级导航、留白与内容区，从柔和青绿过渡到冰蓝；不再限制在插画或局部圆角面板中。深色外观使用独立的低亮度配色，高对比度关闭装饰光晕。下方三个小插画入口分别进入应用、空间分析和隐私。规则、项目清理及可选 AI 调查收进清理选项，不在首页堆叠专业入口和解释文字。

首页吉祥物来自[共享品牌位图](../../../assets/brand/README.md)，组装为 [CleanupWelcomeView.swift](../../../apps/macos/Sources/CleanupWelcomeView.swift)；设置“关于 Shou”在版本旁展示同款应用图标。清理、应用、开发项目、空间、大文件、隐私、启动、规则、历史和设置使用同一套 GPT Image 主题插画，母版、提示词与生成记录见[共享插画](../../../assets/design/illustrations/README.md)。Mac 的 `WorkspaceIllustration` 与 `WorkspacePageArtwork` 加载打包 PNG，Windows 使用相同字节。所有资源随应用打包，运行时不请求网络图片。界面颜色和提取的版式值仍来自共享 token；插画固定使用青绿、奶油白、珊瑚点缀及柔和立体材质，修改时以品牌母版作为参考。装饰空间块不表示实际容量或清理资格，辅助功能忽略装饰层。首页不播放无限循环动画，任务入口的悬停位移遵守减少动态效果。内容不足以容纳时允许纵向滚动，不裁切扫描按钮。

Windows 首页的扫描覆盖问题使用简短状态与详情链接；完整路径按需放入限高、可滚动的浮层，与结果页沿用同一方式。没有可用位置时，“扫描位置”进入已有配置页。不能让长路径错误块常驻挤压扫描按钮和下方任务入口。

其他功能页使用 [WorkspacePageArtwork.swift](../../../apps/macos/Sources/WorkspacePageArtwork.swift) 的同材质独立构图及 `WorkspaceStartPage`。应用与启动项首次进入先展示用途与只读检查按钮，用户启动后显示真实进度与结果；已有结果在切页后保留，不重新插入介绍页。空间与大文件继续保留位置选择，项目复用统一扫描，隐私首页保留时间范围、永久删除影响及支持范围。规则、设置和已有历史直接显示内容，以紧凑插画标题统一视觉；无历史和筛选空结果也有对应插画。任何装饰都不能成为额外的确认授权。

| 页面 | 插画主题 |
| --- | --- |
| 应用 | 层叠应用面板与图标格 |
| 开发项目 | 终端、代码和构建包 |
| 空间分析 | 空间块与磁盘 |
| 大文件 | 文档、媒体与放大镜 |
| 隐私 | 浏览器文档、盾牌与锁 |
| 启动项 | 电源与启动箭头 |
| 规则／设置 | 分层调节面板及勾选／齿轮 |
| 历史 | 操作回执与时钟 |

实用性优先：空间、大文件、应用、启动项和隐私已有结果时不再放大插画或重复页面标题，项目结果仅保留紧凑说明。筛选、列表／树图与底部操作优先使用剩余高度；最小窗口也必须能浏览和操作。

macOS 隐私发现的覆盖缺口在来源列表上方以语义警告色呈现。权限失败增加简短的授权／排除项说明和完全磁盘访问设置入口。可访问来源沿用现有选择流程，不将无法访问的根目录视为空来源或完整扫描。见[隐私清理](privacy-cleaning.md#macos-访问权限与覆盖缺口)。

扫描结果先呈现类别、位置数量和容量估算。类别全宽排列，展开后展示规则／软件，再展开到具体路径；搜索沿用同一组对象。每级复选框都使用当前三态选择，不因为展开或聚焦而改变勾选。

底栏集中展示已选数量、当前选择容量和醒目的红色“永久删除”大按钮。智能清理、开发项目、空间分析、大文件和应用组件清理采用同一交互：列表内审阅与勾选，点击按钮即确认本次范围；冻结选择、校验并执行，不再弹第二次确认。可选废纸篓动作放入次级菜单。手动整目录影响、重建代价和个人数据同意靠近选择项；不得混入自动推荐。准备阶段可停止，受保护位置、排除、所有者和当前清单检查仍由 Core 决定。Windows 系统卸载先在行内审阅安装身份并同意安装程序数据影响，红色卸载按钮提交本次确认，公开执行门禁保持关闭。

空间分析与大文件的列表、树图、导航、选择及直接删除继续使用[空间合同](../product/space-analysis.md)。图形面积表示占用，不能暗示全部可以清理。

## 应用与项目

应用列表采用舒展的对象行：应用图标、名称与版本、状态、容量、最近使用，展开显示关联组件及具体路径。个人数据同意靠近组件选择，归属不明确和共享数据保持保留或不可用状态。应用卸载保留独立的组件、个人数据及系统安装身份核验合同，当前选择通过底栏一次确认，不叠加重复弹窗。

更新检查放在应用行内明细，说明单款查询的网络来源，由用户点击后才开始；展示版本、观察时间和未知原因，官方入口由用户主动打开。复用列表及其展开状态，不添加更新顶级导航。来源与版本限制见[应用更新发现与受控升级](../product/application-updates.md)。

应用下的软件更新页仅以 Homebrew／mise 作为 macOS 更新来源；应用列表不与来源并列。包管理器初始页保留同源插画，检查后让位于全宽列表。名称、当前与目标版本、包类型、可升级资格、搜索、仅看可更新及稳定底栏保持同时可见。单项或批量升级先进入冻结范围的行内审阅，再由强调色“确认升级”执行，不与红色永久删除混用，不叠加第二次确认。结果逐项区分核验成功、未开始、执行前受阻及结果不确定，重新检查后才能再次升级。

Windows 在应用下的软件更新页展示官方 WinGet 来源，由用户点击检查后才读取，保留相同版本对比、筛选和勾选；审阅时完整显示冻结的所选范围，禁用搜索和选择，再由蓝色“确认升级”一次授权，不叠加窗口。列表填满剩余高度，底栏固定；升级时锁定全局导航并阻止关闭，页面切换保留只读检查结果。取消返回选择，停止会等待当前安装程序返回。平台来源不同，不能用不可操作的 Homebrew／mise 空入口假装对齐。参考分析与采用边界见[应用升级设计分析](application-upgrade-review.md)。

Shou 自身更新位于设置“关于 Shou”，不增加顶级导航。沿用原生更新窗口，突出品牌图标、版本差异、滚动说明与主要更新动作；提供检查中、已最新、无兼容更新和连接失败反馈。macOS 显示上次检查与自动检查／安装选项，Windows 便携版明确手动替换步骤，关闭窗口不承诺后台提醒。安装和签名边界见[桌面更新行为](releasing.md#桌面更新行为)。

开发项目以观察到的项目标记归组构建产物与依赖，未识别项目时明确按扫描位置归组。容量仅描述命中的清理项目，不冒充整个源码项目大小。智能清理和项目页复用相同候选身份、规则与选择；项目页操作只准备本页项目范围。具体边界见[应用与项目](../product/apps-and-projects.md)。

## 视觉资源

应用标识使用原创的青绿笑脸收纳盒，奶油色盒盖与珊瑚色拉扣形成稳定识别点。位图母版、生成方式及提示词保存在[品牌资源](../../../assets/brand/README.md)；Mac ICNS 和 Windows ICO 从同一母版生成，检查 16／32／64 px 辨识度。首页与设置关于区展示同源品牌图形，内容主导航不重复品牌区；各页插画沿用同一角色比例、材质、光线及透明背景。官网预留[品牌与插画素材包](../../../assets/brand/web/README.md)，与软件共用事实源。

所有提取的设计值维护在 `assets/design/tokens.json`。macOS 初始页使用 72 pt 主导航，结果／扫描和功能列表使用 48 pt 紧凑主导航；Windows 当前使用 48 pt 主导航。规则、历史、设置标题为 22 pt，其余结果不重复大标题、14 pt 对象正文、40 pt 图标与 28 pt 页面内边距；行内留白和摘要数字同样由资源生成。细节、辅助状态和路径保持足够可读，不能恢复旧版 10 pt 的关键说明密度。

用真实明暗外观检查文本、强调色、选择和焦点。颜色表达状态时必须配文字或图标。图表色板是数据编码，不作为各页面的大面积装饰。系统高对比度、减少动态效果、键盘和辅助功能优先于装饰效果。

执行 `python3 scripts/generate-windows-resources.py` 生成 Windows XAML 与 `ShouDesign.generated.swift`，再运行 `--check`；不手改副本。插画在 Mac 通过 `python3 scripts/workspace_artwork.py` 从批准的位图母版离线导出十张透明 PNG 与摘要清单；Mac 打包并核对所有 PNG，Windows 生成器复制到 `Generated/Illustrations`。新生图使用显式的 `--import-generated` 导入并保留提示词及处理记录；普通导出不访问网络。插画来源变化时先导出再生成，两个脚本的 `--check` 分别核验来源和副本。官网资源使用 `scripts/export-web-brand.py` 导出与校验。文案唯一来源为 String Catalog。Schema 的字段、摘要与拒绝规则由生成器及其测试维护。

## 实现与验收状态

macOS 已构建并覆盖安装新工作台，实际验证范围见 [SYNC.md](../../../SYNC.md)。Windows 源码已替换顶部分组导航、全窗渐变、同源插画初始页和全宽清理列表；项目页现已有 Core 项目标记归组、确切路径、容量去重、三态选择及与智能清理共享的扫描／选择模型；推荐、清除和计划保持项目范围，个人规则须有项目标记并避开固定共享缓存根。分页时说明本页显示数与匹配总数。新项目交互的原生验收和 macOS 手动审阅等价实现仍待完成。2026-10-26 在 Windows 11 x64 云电脑实际构建 WinUI，并通过 Computer Use 检查初始页、只读扫描、展开、选择、小窗口及明暗切换；设置与隐私行模板的 Double／GridLength 资源类型错误已修复，代码生成控件使用动态主题资源。截图和失败回执见 [Windows 测试记录](windows-testing.md#2026-10-26-windows-11-云端验收)。公开变更、完整桌面 E2E、ARM64 完整界面、签名安装及逐页 macOS 等价验收仍未通过。

使用生成数据覆盖空、加载、部分覆盖、就绪、确认、执行、停止、失败和完成。验证顶部与次级导航、展开与勾选、筛选后选择、底栏容量、取消确认、最小窗口和明暗外观。只用生成夹具验证删除；真实个人数据只允许只读检查及取消。构建、状态测试和资源检查不能代替真实 UI 或签名安装证据。

## 系统监控

监控采用两排八个资源面板：资源状态、CPU、GPU、内存；电池、磁盘、网络、温度与风扇。趋势嵌入对应面板，下方为全宽进程列表与搜索／排序；每核 CPU 与内存细节渐进展开。保留当前全窗渐变、半透明可读表面、共享圆角与正文尺寸，在 960 × 680 的窗口通过滚动浏览。资源状态说明负载依据，不显示无来源的健康分数；传感器未知显示缺失。菜单栏、Dock、托盘与支持的任务栏入口复用相同采样状态及文案，提供打开、暂停与关闭摘要，退出沿用原生生命周期。指标、权限与验证以[系统监控合同](../product/system-monitor.md)为准。

## 界面风格基线

适用于本仓库全部原生页面，包括已增加的开发者工具、AI 工作台、MySQL 管理及升级界面。旧页面同样需要按此基线修复。

1. 不用中点分隔文案。来源、版本、状态优先分列；标签和值用冒号，连续项目用逗号或换行。用户原始文件名、代码和日志保持原样。
2. 删除重复标题、常驻操作教程及冗余解释。保留当前状态、范围、限制、失败原因和操作后果；后果放到既有审阅处，不重复确认。
3. 文案面向当前界面的用户，准确、简洁、易懂。按钮使用明确动词，不口语化、不造词，不把实现细节当产品说明。
4. 自定义界面颜色全部使用 [Radix UI Colors](https://www.radix-ui.com/colors/docs/palette-composition/understanding-the-scale)。设计值只改共享 token；[色阶映射](../../../assets/design/radix-colors.json)记录官方版本与每个 token 的来源，由生成器离线核验。Slate 为中性色，Teal 为强调色，Green／Amber／Red 表示成功／注意／危险。1–2 阶用于背景、3–5 阶用于交互表面、6–8 阶用于边线与焦点、9–10 阶用于实色动作、11 阶用于辅助和语义文字、12 阶用于主要文字。强调文字使用 Teal 11，实色按钮须验证对比度。系统窗口与高对比度模式保留系统无障碍语义；品牌位图不属于界面色板。
5. 检查文字基线、图标视觉中心和表格列对齐。嵌套圆角按外圆角减内边距处理；内层不大于外层，空间不足时使用直角，避免重复套卡片。
6. 自定义边框和分隔线统一为共享 `ShouHairlineWidth = 0.5` 逻辑单位，macOS 为 pt、WinUI 为 DIP。系统焦点环及图表数据线保留功能尺寸。
7. 默认无装饰动画。必要过渡采用 ease-out／250 ms，遵守减少动态效果；不为刷新同时放置多个 loading，不播放无限装饰动画。
8. 每页优先三档字号，最多四档，最小 12。工作页使用 12／14／22：正文 14，路径和辅助状态 12，主要标题 22。其余层级用字重、语义色和间距表达，不缩小文字腾空间。图标尺寸单独审阅。
9. 减少额外决策，必要选择在原有来源、对象选择或审阅处完成。保持精确范围和单次确认合同，不增加重复弹窗，也不删除必要后果说明。
10. 圆角和阴影服务控件边界，避免装饰每个区块。列表优先留白和 0.5 分隔线，不添加卡片左侧彩线；开关保留胶囊形态和可用操作区域。
11. 移除只重复标题的 Eyebrow／Overline，不用英文大写小标签装饰区块。仅在提供额外分类或上下文时保留，通过字体、字重和留白建立层次。
