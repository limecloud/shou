# 调查实现合同

[English](../../engineering/embedded-ai-investigation.md) | 简体中文

## 输入与输出

接受用户明确目标、当前本地扫描、所选范围和所选供应商，仅按产品披露读取有界证据。不通过隐式工具发送原始文件正文、密钥或无关路径。

输出证据、聚焦问题、独立规则建议、保留路径、限制和实际服务用量。建议是禁用草稿，创建、校验、预览、启用、重新扫描和确认清理分别处理。

## 状态与路由

使用运行、等待、完成、受限、取消与失败等已定义领域状态。未配置、停止中等 UI 状态不能伪造领域完成。优先确定性本地证据、可选结构化决策与必要主模型升级，遵守各服务凭据可用性与用户路由策略。

持久化问答检查点和原连接引用，继续前重新验证范围和有效期。取消撤销后续请求，保留真实结果。HTTP 重定向、重试、超时、载荷上限与预算遵循明确通信合同。

## 平台实现

macOS 桌面与 CLI 共用 `ShouAI` 服务及固定 Swift SDK 和有界通信。Windows 桌面与 CLI 后续共用独立 .NET 调查服务，使用 Windows 原生凭据和本地记录。通过共享案例与 [SYNC.md](../../../SYNC.md)对齐产品语义和声明式规则输出。

## 验证

使用生成证据和本地模拟服务，检查协议、前缀、认证、取消、预算、注入和范围。仅在获得授权时增加真实供应商证据。原生 UI 另行验证问答、逐条草稿、预览、离线清理和恢复。见[AI 架构](../architecture/embedded-ai.md)与[验收](embedded-ai-acceptance.md)。
