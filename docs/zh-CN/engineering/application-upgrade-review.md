## 采用的任务与设计

| 实际观察 | Shou 的采用方式 |
| --- | --- |
| App／Homebrew／mise 按来源分组 | Mac 应用页内切换来源；Windows 使用官方 WinGet，保留平台差异 |
| 已安装版本与候选版本邻近展示 | 每行对比版本，未知不显示为最新；固定与不受支持的版本不授予升级资格 |
| 搜索、仅显示可更新项、检查更新、全部更新 | 搜索与筛选服务于选择；整批操作列出冻结的软件与目标版本再确认 |
| 应用明细的来源与更新入口 | 保留现有应用明细的只读目录查询；没有具体路径归属证据时，不把 Cask 记录绑定为应用副本的更新授权 |
| 紧凑列表与明确主操作 | 沿用 Shou 顶部工作台、全窗渐变和同源插画；结果页压缩装饰，底栏始终保留可见的强调色升级动作 |

参考界面同时包含大小、上次打开、运行状态等信息，不意味着这些字段均属于本轮升级能力。Shou 不添加未实现的指标、恢复或任意来源安装；执行进度与安装核验独立于清理记录和释放空间统计。构建、生成夹具、真实只读列表、实际安装、Windows 原生 UI 各自取证，不能互相替代。最终结果见 [SYNC.md](../../../SYNC.md) 和证据目录内报告。
