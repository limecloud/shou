# 日常清理交付要求

[English](../../engineering/cleanup-delivery.md) | 简体中文

| 工作项 | 必需行为 | 平台状态 |
| --- | --- | --- |
| N01 | 编排有界根任务，保持文件系统证据一致 | macOS 已有源码，需原生验证 |
| N02 | 过期和配额回收，保护活跃计划与恢复引用 | macOS 已有源码，需失败场景 |
| N03 | 固定工具操作、本地上下文与有界输出 | macOS 已有源码，使用生成工具夹具 |
| N04 | 关闭所有者、刷新受影响范围与明确重试 | 各平台分别实现，活跃状态未知则阻断 |
| N05 | 残留清理需确认所有者缺失，个人数据独立同意 | macOS 已有源码，明确支持的关联 |
| N06 | 原生 Windows 扫描与清理 | 按 Windows 阶段待实施 |
| N07 | 调查产生独立、可复用个人规则 | macOS 已有源码，质量与 UI 分别验收 |
| N08 | 版本、文档、资源和分发匹配实际验证版本 | 各次发布独立取证 |
| N09 | 大型不可变回执清单与引用保护 | macOS 已有源码，需中断写入验收 |

每项以纵向链路实施和验证。性能优化必须保持选择、保护、清单、回执和取消行为不变。规则可复用不代表可以省略当前证据或确认。

Windows 遵循[原生方案](windows-native-plan.md)，在 [SYNC.md](../../../SYNC.md)登记功能与安全对齐。实际检查结果进入对应版本的验证报告，不能成为永久产品支持声明。
