# 应用与项目

[English](../../product/apps-and-projects.md) | 简体中文

“应用”组织已安装应用、软件更新与启动项。项目产物属于智能清理，从清理选项进入项目清理，不再与应用并列。macOS 已有应用列表、关联组件审阅、项目产物归组、共用规则选择、单应用只读更新发现，以及审阅后执行的 Homebrew／mise 软件包升级。Windows 有独立更新发现及官方 WinGet 升级源码，也有对应导航、项目标记归组和共用扫描／选择模型。无人值守安装、Git 远端状态调查和整个项目删除不在本轮范围；原生验收及手动审阅差异分别跟踪，源码存在不代表双端已经完整对齐。

Core 去重清理候选，并将共享内置项目模板及具备项目证据的个人规则投影到项目页；项目页的推荐、清除与计划只作用于该范围，保留页外缓存选择。软件包升级使用独立选择和授权路径。

智能清理与开发项目、应用组件、空间分析和大文件清理共用一次范围确认：列表内审阅与勾选后，点击底部红色“永久删除”冻结当前选择，校验后执行，不再重复弹窗。项目清理仍只操作本页范围；应用个人数据同意及管理员认证保持各自约束。

## 应用

应用本体、可核验的关联缓存与用户数据在同一行展开。每个组件保留确切路径、容量估算、归属与当前资格。运行中的应用、重复安装、共享组件和无法确认归属的内容继续遵循[应用卸载](application-uninstall.md)的独立合同。

应用残留从应用页进入；启动项作为同组的独立任务使用现有系统适配。视觉合并不把缓存规则变成卸载授权，也不把启动注册信息变成清理权限。

只读更新发现沿用应用行内明细，由用户主动查询单款应用的公开目录版本并打开官方入口；未知不显示为“已是最新”。来源、网络、版本和身份边界见[第三方应用更新与受控升级](application-updates.md)，不与本产品自身更新混用。

## 软件包与升级

应用下的软件更新页在 macOS 提供 Homebrew 与 mise 来源，在 Windows 提供官方 WinGet 来源；进入页面不自动检查。用户可搜索来源识别的已安装记录、筛选更新并选择合格目标。软件包记录本身不能证明某个应用路径或项目归属；没有可靠映射时不自动并入应用卸载勾选，也不重复计算其清理容量。

升级须审阅并确认冻结的确切选择，再次核对来源／身份／版本，逐项记录真实结果。这是独立安装任务，使用自身动作文案和短期、单次授权，不能复用红色永久删除动作、清理同意或上次升级许可。管理器／安装器可能调整依赖和数据，取消不等于回滚，未知结果须先检查已安装版本再决定是否重试。

mise 仅处理合格的用户全局 `latest` 请求，不操作项目版本、项目配置及项目锁文件；管理器仍可能更新全局锁文件。Windows 保留已核验安装范围与官方目录确切目标，不静默接受协议或重启，停止后等待已派发安装器的结果。完整限制与验证边界见[更新合同](application-updates.md#软件包受控升级)。

## 开发项目

本地开发、自建项目和克隆项目共用扫描。来源平台不决定清理资格。Core 根据扫描已经观察到的清单标记，将同一项目下的构建产物和依赖归组；不能确认项目根时，界面明确“按扫描位置归组”。项目列表不另读源码正文、不执行 Git 网络请求，也不以远端存在为由认定内容可恢复。

容量标注为“匹配的清理项目”，仅汇总已经去重的候选，不能当作整个项目大小。构建产物、依赖和个人规则命中项按具体路径选择，源码目录、清单、锁文件和受保护数据仍保留。包管理器的全局共享缓存保留在智能清理的工具类别，不因选择一个项目连带选中整个共享存储。

Windows 个人规则只有在其候选上方观察到普通、单链接的项目标记，且扫描根与共享目录中的固定缓存位置互不重叠时，才进入项目投影；没有标记、位于缓存根或缺乏目录事实源时仍仅在智能清理显示。注册引用或目录名称不能替代这些证据。两端标记归组只使用本候选所属快照的观察；Windows 区分大小写目录与相似前缀。

智能清理与项目页共用候选身份和选择集合。项目页的按钮只准备项目来源的已选项目；智能清理底栏仍明确汇总其全部已选范围。搜索只改变可见列表，不授予新的权限。确认前继续去重父子路径并复核当前清单。

## 规则与执行

内置规则与明确启用的个人规则共用一个规则来源，不复制一份项目专用规则。自动推荐与手动审阅分开；手动审阅在准备阶段重新完整计量，不能拿扫描时的不完整清单直接执行。

默认清理为永久删除，确认准确路径和不可逆后果；选择废纸篓时使用独立动作名称，不宣称已释放同等空间。项目页不提供整项目删除、自动放弃 Git 改动或删除 worktree 的快捷动作。未来如需这些能力，必须单独设计未提交、未跟踪、未推送、共享对象和本地配置的影响合同。

## 验证

领域夹具检查项目归组、候选身份、容量去重与应用缓存分离；现有清理测试继续检查永久删除、保留源码、排除、变化后拒绝和无确认不删除。升级夹具独立检查冻结目标、重查、单次授权和未知结果；原生界面、管理器／安装器及打包安装分别取证，不能以纯 .NET 或生成管理器夹具代替原生 WinGet 验收。原生界面另行验证同组导航、展开、选择、容量反馈、项目范围审阅和取消。当前结果见 [SYNC.md](../../../SYNC.md)。
