# 系统监控

[English](../../product/system-monitor.md) | 简体中文

系统监控是独立的只读任务，沿用顶部工作台和贯穿全窗的青绿至冰蓝渐变。上方两排八个指标面板，下方全宽进程表；面板内显示真实读数与两分钟短期趋势，不展示虚构的健康分数、温度或能耗。

## 指标与计量

| 指标 | macOS | Windows |
| --- | --- | --- |
| CPU | Mach 每逻辑核累计 tick 差分，整机均值 | 单 processor group 使用 GetSystemTimes；多 group 使用完整 PDH 逻辑核集合均值；PDH 提供每核数据 |
| GPU | IOAccelerator 可读设备利用率中的最大值 | PDH GPU Engine 按物理引擎合并进程贡献，显示最繁忙引擎；不是不同引擎相加 |
| 内存 | 物理总量减 free 与 inactive，压缩页、交换使用量与系统压力独立观察 | 物理总量减 available；压缩、交换和内存压力在当前 API 无明确事实时为不可用，不用 commit 代替 swap |
| 磁盘 | 系统卷总量／可用量，IOBlockStorageDriver 累计读写字节差分 | 系统卷总量／可用量，PDH PhysicalDisk 原始累计读写字节差分，排除 `_Total` |
| 网络 | 活动的 `en` 数字接口，排除 loopback 和 tunnel | 活动的 Ethernet／Wi-Fi 接口，可能包括被系统归为 Ethernet 的虚拟适配器 |
| 电池 | IOPS 电量／供电，AppleSmartBattery 可读原始容量比与循环次数 | GetSystemPowerStatus 电量／供电；当前无可靠健康／循环数据时显示不可用 |
| 温度／风扇 | 固定 AppleSMC 只读协议及已识别芯片传感器；可读传感器均值和实际转速，系统热状态独立展示 | 当前支持的只读系统 API 不提供统一 CPU／GPU 温度及风扇，明确显示不可用；不安装驱动或提权 |
| 资源状态 | 仅依据当前 CPU／内存占用：任一达到 90% 标记高负载；macOS 严重热状态也标记高负载。暂停、失败或缺少任一负载时为观察不完整 | 同一负载口径；这不是硬件健康诊断 |

无内置电池、权限不足、驱动不提供计数器、未知芯片、失效传感器等都保留缺失状态。界面用 `—` 和附近原因表达，不能把不可读值写成零。真正读取到的零负载或零转速可以显示零。风扇不提供写入模式或转速控制，电池不提供充电设置。

## 采样与生命周期

每个窗口只有一条串行采样链，正常间隔为两秒。首样本建立 CPU／IO／进程速率基线。计数器倒退、磁盘或接口集合变化、单调时间间隔无效或超过三十秒时，相关速率缺失并重建基线；暂停恢复与错误恢复同样重置。Windows PDH 自带差分值也必须通过当前新基线检查。

最多保留六十个样本，趋势横轴使用真实时间、覆盖最近两分钟；缺失与长间隔断线。历史仅驻留内存，不写入清理记录，不上传。采样失败保留旧图和上次时间，同时明确标记失败。切页或关闭窗口停止前台采样，只有用户主动开启菜单栏／托盘摘要时才允许继续；暂停停止两处采样。取消、恢复、关闭或释放后的迟到结果不能更新状态，也不能与新读取重叠。

macOS 保留系统正常的关窗与退出区别。Windows 正常关窗沿用退出行为并移除托盘图标。两端退出都释放采样及摘要资源；不暗中拦截退出，不添加开机启动。

## 进程与桌面入口

只读取 PID、开始时间、短名称、累计 CPU 时间和驻留大小。PID 与开始时间共同标识实例，避免 PID 重用产生错误速率。CPU 按整机全部逻辑核总容量归一为 0–100%，不同于可累计超过 100% 的按单核显示方式；驻留内存包含可能重复的共享页，不相加冒充整机已用内存。

每轮最多检查 4,096 个进程，进程阶段预算为 0.6 秒；进程退出、拒绝读取或预算耗尽时标记部分覆盖。支持名称／PID 搜索、CPU／内存排序，最多显示前 100 个匹配结果，并显示可读范围与匹配总数。不读命令行、环境或文件正文，不提供杀进程、内存清理和批量终止。

菜单栏与托盘均由用户开启，展示 CPU／GPU、内存、磁盘读写、网络收发、电池、热状态／风扇及前三个 CPU 进程快照，注明采样状态／时间，提供打开监控、暂停／继续、关闭摘要与正常退出。macOS Dock 提供监控入口和启用摘要后的暂停／继续；Windows 在系统支持 Jump List 时注册打开监控入口。桌面入口复用同一状态和采样源，不另起轮询。Windows 图标属于窗口，语言重载／关窗释放，Explorer 重启后尝试恢复。

## 实现与验收

Swift／C# Core 定义观察、差分与有界历史；Platform 只读采集；Swift Session／Windows Presentation 管理生命周期；SwiftUI／WinUI 只呈现与调度。共享文案从 String Catalog 生成，视觉复用现有 token。

验收覆盖首样本、倒退、长间隔、来源变化、多 processor group 完整性、PID 重用、缺失、历史上限、暂停、隐藏、背景启用、错误、迟到结果及释放。原生采样、WinUI 编译、桌面交互、菜单／托盘、最小窗口、明暗外观和安装分别取证；实际状态见 [SYNC.md](../../../SYNC.md)。本功能不修改已发布的 `v0.15.0` 标签或清理安全合同。
