## 任务与对象

MySQL 使用专属任务页：服务、版本管理、数据库与账号、配置文件、日志、慢查询日志和实例组。安装副本、运行实例、数据库账号不是同一个对象。服务沿用[逐软件生命周期合同](../engineering/developer-tool-adapters.md)，数据库操作另由 Swift `MySQLAdministration` 和 `MySQLAdminOperating` 定义，不复用通用软件安装命令。

选择实例时展示安装路径与配置路径。数据库连接只支持本机 TCP 127.0.0.1 或用户确认的 Unix Socket，使用所选安装旁的 `mysql`／`mysqldump`。连接后显示实际服务 UUID、版本、端口、数据目录及认证账号；操作前重新核对身份，端口复用或实例改变时拒绝变更。MySQL 客户端使用独立配置、隔离 HOME 和 login-file 路径，避免个人默认连接覆盖本次目标。

## 数据库与账号

- 查询数据库名称、字符集及精确 User／Host／认证插件，不读取业务表内容。账号权限不足时保留数据库结果并明确限制账号功能，不能显示虚假的空账号列表。
- 创建数据库与创建账号分别审阅。新账号只允许 localhost，并只获得所选数据库权限；不重用任何既有用户名，不修改既有账号口令，不添加全局权限或转授权。MySQL 的数据库授权通配符和 `partial_revokes` 分别处理，库名中的下划线不能扩大到其他库。
- 密码修改使用当前已认证会话，并绑定 User 与 Host。变更后用新凭据核验实际账户；不能核验时保留需要核实的结果，不自动重试。不会自动进入跳过认证的维护态或停止真实服务器。
- 本地备注按服务 UUID 与库名保存，仅属于 Shou 展示。不会从数据库读出明文密码，也不把本地记忆的口令当作数据库事实。连接凭据只在内存会话中使用；临时客户端配置为当前用户私有，操作日志不保存凭据或 SQL 正文。

建库、账号授权及密码修改使用两分钟内有效、只能消费一次的内存审阅。当前源身份与数据状态复核后，先保存无凭据的意图，再派发 SQL 并保存结果。多个 SQL 步骤不构成事务；失败可能留下已完成的部分，结果要求重新连接和核实，不自动补偿、重放或改动其他账户。

## 配置与日志

配置页显示所选确切 `.cnf` 原文，支持选择其他明确文件。拒绝链接、特殊文件和多硬链接；编辑只处理当前用户可写文件，不改变权限或提权。保存前复核身份与原文，先保存摘要意图，在同一文件句柄上写入并读回核验。外部变化阻止保存；与不遵守文件锁的外部程序之间不承诺原子比较交换。不会将含潜在凭据的配置正文复制进普通记录，不会自动重启或宣称已通过 MySQL 语法验证。

`[mysqld]` 的端口、Socket、datadir 与日志路径只作为当前文件线索；include 文件和命令行覆盖仍须分别核实。错误与慢查询日志独立呈现，可选择确切日志，读取最近 200 行／64 KiB。未配置、无法读取和真实空文件分别显示；不自动开启慢日志或清空日志。Shou 的启动输出保持独立；配置尚在后台读取时，完成后自动重新读取当前日志页，不把启动输出当作缺失业务日志的替代。

## 备份与实例组

勾选非系统数据库后，由用户选择本地目的目录。`mysqldump` 输出流写入新建的私有 `.sql.partial` 文件，不经 Shell、不将整个备份载入内存、不覆盖同名文件。成功退出、文件非空、数据刷盘和服务身份复核后改为 `.sql`；逐库保留成功与失败结果，失败文件保留 `.partial`。使用 single-transaction／quick，但不能承诺非事务表的在线一致性；运行时不将导出成功等同于恢复验证。未提供导入或数据库删除功能。

实例组创建全新私有目录、配置、数据目录、端口和 Socket。使用所选安装执行安全初始化，从创建时设置 root 密码，监听仅限本机；创建后保持停止，不迁移或复用旧数据，不设置登录启动。初始 SQL 通过已取消目录链接的私有输入句柄提供，不留下命名口令文件。初始化失败保留文件和受阻结果，不自动删除、清空或重新初始化数据。组登记后使用同一确切实例启停合同，不伪装为批量启动分组。

实例组页逐行显示已核实状态、PID、胶囊启停和重启，复用服务控制器的一次观察、执行前复核及真实结果。管理菜单直接打开该组的数据库、配置、错误／慢日志及独立启动输出，也可复制 Socket 路径。状态未知或旧观察失效时不授予控制；失败保留原因与日志入口。

### 登记变更

`MySQLInstanceRegistry` 定义重命名、更新启动登记和移除登记三个用例，通过小型平台接口完成。审阅绑定组记录、程序与数据目录身份、确切配置及端口／Socket，两分钟内有效且仅能消费一次。执行取得同一记录租约，重新核实、先写意图，再更新登记与结果；失败不自动重放。

这些动作只允许已核实停止的独立实例。同一程序下其他明确配置的运行实例不阻断本组；无法区分的运行实例会阻断。保存配置后，旧配方失效；在实例组页“审阅更新后的配置”核对新端口后重新登记，即可让下一次启动绑定新文件。此流程限定 Shou 创建的独立组，要求唯一明确的 `[mysqld]`、仅 loopback 监听、原数据／PID／日志／Socket 路径，拒绝 include 和重复／不明确的关键设置；不更换数据目录或自动启动，也不宣称已验证全部 MySQL 配置语法。

移除登记只取消组与已保存的停止配方，不删除数据库、配置或日志，不释放空间；运行中必须先停止。已缺失生成数据目录的登记仍可在核实没有对应运行实例后移除。真实进程再次在外部启动仍会被服务发现，不能通过移除登记隐藏运行事实。批量控制和安装版本／数据目录迁移尚未实现。

重新登记只接受完整明确的选项名：生成的连接与路径设置，以及 `slow-query-log`、`long-query-time`、`max-connections`、`innodb-buffer-pool-size`、`character-set-server`、`collation-server`、`sql-mode`、`default-time-zone`。拒绝其他选项、插件加载、`loose`／`skip` 等别名与缩写，避免覆盖审阅中的监听范围或路径。下划线统一为连字符后检查重复；错误与慢日志均绑定本组原路径。原文编辑器仍可保存其他配置，保存成功不代表已取得启动登记资格。

## 尚未对齐的能力

停止实例的恢复配方绑定配置身份；独立组已有明确的重新登记入口，任意外部实例的配置变更后重新登记仍未接通。配置页保存成功不代表下一次启动已经验收。工作目录可被组或其他用户写入的既有实例显示具体权限缺口并保留运行事实，当前不会授予重启权限，不自动修改个人数据目录权限。

MacPorts 来源、额外版本线、phpMyAdmin 自动站点部署、忘记密码的维护态恢复、实例组的安装版本／数据目录迁移及批量控制，以及其他软件的专属业务功能仍未完成。现有 Homebrew 来源列表不代表支持全部来源；MySQL 新增任务不能被套用于 MariaDB、PostgreSQL、Redis 或其他软件。后续按[逐软件适配设计](../engineering/developer-tool-adapters.md)分别实现并取证。
