# 第三方应用更新与受控升级

[English](../../product/application-updates.md) | 简体中文

应用提供两条独立更新路径：已识别应用的只读目录发现，以及通过受支持包管理器审阅后升级已安装软件包。两者均不复用卸载勾选或清理授权；Shou [自身更新](../engineering/releasing.md#桌面更新行为)保持独立。源码、测试、原生界面及分发状态分别记录于 [SYNC.md](../../../SYNC.md)。

下文先保留单应用发现及 CLI 合同，再由[软件包受控升级](#软件包受控升级)说明 macOS Homebrew／mise 与 Windows WinGet 的独立实现。

## 来源和身份

首个来源为 `formulae.brew.sh` 的固定 HTTPS JSON API。内置[映射](../../../packages/shou-core/Sources/Resources/application-update-sources.json)按确切 bundle identifier 与应用包文件名识别六种稳定版应用：Visual Studio Code、Firefox、iTerm、Chrome、VLC 和 Postman。测试版、重命名包、系统应用及没有可核验元数据的对象不自动匹配。映射不证明应用通过 Homebrew 安装，也不证明本地应用包的开发者签名。

本地读取复用现有应用盘点及其有界、不跟随链接的元数据合同。检查前核对当前应用；GUI 同时绑定行内已观察的完整应用身份。网络成功或失败后再次读取本地身份，变化时拒绝发布该检查并要求重新扫描。

## 查询与隐私

单应用发现中，展开明细不联网。“检查 Homebrew 目录”明确说明查询目标，由用户点击才发起请求；每次只发送映射的 cask 标识，不发送本地路径、已安装版本、用户名、应用清单或凭据。该目录查询不执行 `brew`、Shell、下载包或应用更新器，不打开业务记录存储。

请求禁用 Cookie、缓存和持久凭据，使用系统 TLS 验证；拒绝重定向及交互认证。请求超时十秒、总请求期限十五秒；接收前及接收中限制响应不超过 1 MiB，只有 HTTP 200 与 JSON 类型进入解析。错误只保留固定原因码，不展示自由格式服务器错误或认证信息。取消后不发布迟到结果。

## 版本与结果

只比较最多八段、每段最多九位的点分 ASCII 数字版本，忽略数值相等的尾部零。`latest`、预发行版本、逗号构建后缀、非法数字及格式不明均保持未知。按当前 macOS／架构选择已知目录变体，并检查其 macOS 条件；不据此声明下载产物的架构、签名或安装兼容性已验证。

| `state` | 含义 |
| --- | --- |
| `newer_catalog_version` | 目录中存在数值更高的版本，可打开官方目录页面 |
| `same_catalog_version` | 版本数值一致，不承诺应用已经是最新或该渠道立即可升级 |
| `installed_version_newer` | 已安装版本高于目录版本，不建议降级 |
| `unsupported` | 无内置来源，不发起请求；引导使用应用自身更新器 |
| `unknown` | 网络、身份、平台条件、元数据或版本口径无法核验，不能误报没有更新 |

报告 `format_version=1`，保留观察时间、应用身份、来源、已安装／目录版本和固定原因。未知报告 `status=partial`／CLI 退出 `6`；其他状态表示本次查询已完成，不表示安装通过验证。应用在查询期间变化返回 `application_changed`，取消遵循既有取消合同。

“打开 Homebrew 页面”只打开固定来源的官方 cask 页面，不使用响应中的任意 URL；安装由应用或官方更新器接手。该入口不创建下载、替换、安装、管理员授权或长期更新许可。

## CLI

```sh
shou applications updates source --path "/Applications/Visual Studio Code.app" --json
shou applications updates check --path "/Applications/Visual Studio Code.app" --allow-network true --json
```

`source` 只读本地身份与映射；`check` 必须明确传入 `--allow-network true`。无映射时即使允许联网也不请求网络。两者使用[标准机器信封](../ai/agent-and-cli-contract.md)，不打开或创建清理存储。

## 只读发现的实现与验证

Core 拥有映射、严格版本比较、平台条件、未知状态和身份复核；Platform 负责原生应用读取及固定来源的有界网络请求；UI 只负责行内呈现、取消和用户主动打开官方页面。复用[当前设计](../engineering/interface-design.md)，不新增顶级更新页面。

生成夹具覆盖来源／包名不匹配、相等／更高／更低版本、含糊格式、不同平台变体、系统条件、查询期间应用变化、取消、离线、错误响应、JSON 类型及响应大小。真实目录连通、GUI、辅助功能和安装后行为分别取证，不以模拟网络或构建通过代替。该只读路径不产生安装授权；下文独立的软件包升级须另外明确选择与确认。

## Windows 来源与差异

Windows 的首个来源为 `https://api.github.com/repos/microsoft/vscode/releases/latest`，只观察 Visual Studio Code 稳定发布。内置匹配限定 x64 的当前用户或计算机 64 位注册视图、确切卸载注册键、显示名称和 `Microsoft Corporation` 发布者；不匹配便携、Insiders、其他架构、改名或未知注册。注册匹配不证明安装来源或签名。匹配事实可与 [GitHub Desktop 的 Windows 编辑器目录](https://github.com/desktop/desktop/blob/development/app/src/lib/editors/win32.ts)核对；这里不执行其中的外部命令或复用其源码。

行内展开只显示本地来源，点击“检查版本目录”才查询固定公开端点。请求无认证、Cookie 或应用清单；拒绝重定向，十秒 HTTP／十五秒总期限，流式接收限制 1 MiB，仅接受 HTTP 200 和 JSON。Core 核对非 draft／非 prerelease、确切仓库发布页和纯数字标签，不使用返回的包地址。官方入口固定为 `https://code.visualstudio.com/updates`。该目录仅为发布版本观察，不证明某个 Windows 安装包适合当前系统。

```sh
shou applications updates source --application-id ID --json
shou applications updates check --application-id ID --allow-network true --json
```

调用前后独立重读完整应用盘点；盘点不完整或注册身份变化时拒绝结论。`source` 不联网，已识别但尚未查询的来源状态为 `not_checked`；`check` 的未知结果使用部分状态与退出 `6`。查询取消或应用行切换后，旧结果不能覆盖当前行。Windows 原生注册、WinUI 与包内 CLI 分别取证。

## 软件包受控升级

软件包视图展示来源能识别的软件包、已安装／可用版本及当前升级资格。搜索与仅看更新只改变可见范围，不授予权限。软件包记录不能证明它归属于某个应用包、卸载注册或项目；没有可靠映射时保持独立，不自动并入应用卸载勾选，也不把其内容重复计为清理容量。

用户先审阅确切选择及安装影响，再确认升级。审阅范围冻结为短期、单次计划，不成为长期许可、无人值守更新或清理计划。来源、安装身份或目标版本变化会使对应授权失效；再次尝试必须重新检查与审阅。包管理器及安装程序可能下载文件、运行安装脚本、关闭应用，并修改依赖或应用数据；Shou 不提供升级回滚，也不自动重启电脑。

### macOS：Homebrew 与 mise

应用下的软件更新页提供 Homebrew 和 mise 来源切换，与应用管理分开；由用户点击检查后读取。软件包视图支持清单、搜索、更新筛选、单项审阅及选中／全部可升级项审阅。“审阅全部”冻结本次清单中的具体合格目标，执行时仍逐条传入明确的软件包标识，不调用不带目标的全部升级命令。审阅在当前页面替换工作选择，由一次“确认升级”动作授权。

| 来源 | 盘点与目标范围 | 升级边界 |
| --- | --- | --- |
| Homebrew | 已安装 Formula、依赖和 Cask，使用管理器 JSON 元数据观察可用版本 | 每项调用 `brew upgrade --formula TOKEN` 或 `brew upgrade --cask TOKEN`；固定版本及无法核验的目标不可升级 |
| mise | 已安装全局工具及其配置请求 | 仅单个 active、已安装、来自受支持用户全局配置且请求为 `latest` 的工具；每项调用 `mise upgrade --global --no-prune TOKEN` |

Homebrew 元数据可能来自缓存：这些进程禁用自动刷新目录、分析上报和安装后清理，因此检查不承诺远端最新发布。查询目标失败时可保留已安装清单，并明确更新状态未知，不能据此升级。管理器配置的 tap／backend 和安装脚本仍有自己的网络与执行行为；单应用目录查询的窄请求与隐私保证不能套用到这些进程。

mise 固定版本、版本范围、项目配置及项目锁文件不进入此升级路径；非 active 或多版本观察含糊时保持只读。管理器可能更新用户全局锁文件，`--no-prune` 不表示所有全局元数据均保持不变。

Platform 只从受支持位置定位管理器，核验当前用户或 root 所有的可执行文件，拒绝组／其他用户可写的程序；通过固定参数数组直接启动，不经过 Shell，限制输出及执行期限，标准输入不可交互。不自动安装缺失管理器、不替用户接受协议或取得管理员凭据。这些措施限制 Shou 的调用，不构成管理器及其插件的执行沙盒。

Core 只接受当前服务保存、不足十分钟的观察，并签发 120 秒计划。执行在预检前消耗计划，先重查整批冻结范围，再逐项核对软件包元数据及管理器身份，串行执行；实际派发每项命令前重新检查期限，慢盘点或前项耗尽期限时不再派发。命令不传入锁定版本参数：冻结目标用于后续安装核验，管理器也可能调整依赖。若前一项已通过依赖安装了另一所选项的确切目标，则核验后计为完成，不重复派发升级。

成功须在命令结束后观察到已安装版本包含审阅目标，进程成功退出不能单独作为成功证据。派发前阻断记为失败，派发后无法核验记为未知，出现这些失败时后续未启动项跳过。停止或超时可能在部分文件已经变化后终止 Shou 自有进程组，不提供回滚，不能显示为“安装未变化”。结果清空旧盘点，再次尝试须重新检查。

### Windows：官方 WinGet 目录

应用下的软件更新页提供官方 WinGet 来源，由用户点击检查后读取，使用 Windows Package Manager COM API，不解析本地化 CLI 表格。只连接预定义官方 WinGet 源，核对固定身份 `Microsoft.Winget.Source_8wekyb3d8bbwe`、`Microsoft.PreIndexed.Package` 类型，以及 `winget.azureedge.net/cache` 或 `cdn.winget.microsoft.com/cache` 的官方 HTTPS 端点。不添加、重置或修复来源，不接受来源协议，不连接 Microsoft Store 或任意用户来源。

有界盘点只包含官方目录能匹配的已安装包。可升级项须具备已知安装版本、核验后的当前用户／计算机范围、ProductCode 或 PackageFamilyName 身份、同渠道更高目标、唯一的目录／版本／渠道组合及可用安装程序。身份未知、目标含糊、要求接受包协议或盘点不完整均不能执行；这些检查不代表能覆盖所有已安装应用。

页内列表展示软件包 ID、版本和安装范围，填满剩余高度，操作底栏固定。“审阅所选更新”重新核对并冻结选择，完整显示所有所选软件，包括被搜索或筛选隐藏的条目；审阅期间禁用搜索和选择。蓝色“确认升级”只授权本次计划一次，不再叠加弹窗；“取消”返回选择，不派发安装程序。Core 在签发两分钟单次计划前、整批派发前和每项之前重读；Platform 在派发前再次核验确切软件包及授权期限。升级保持已观察的用户／计算机范围和确切目标，使用静默安装、跳过自动安装依赖，不启用强制、忽略哈希、未知版本升级或自动接受协议。安装程序仍可能要求 Windows 管理员批准或影响自身数据，Shou 不提供事务保证。

停止后不再启动新项；已经派发的 COM 安装等待真实结果，不取消该安装，窗口保留至结果返回。完成后即使用户已停止，也用独立有界盘点核验版本。只有管理器成功且观察到确切目标安装版本才算已核验；失败不承诺安装程序未改变文件。无法核验记为未知并停止后续项，未启动项单独标记。需要重启时仅报告，不代为重启 Windows；再次尝试须重新检查与审阅。

### 验证边界

领域测试及隔离生成的管理器夹具覆盖冻结选择、身份／版本变化、计划过期与重放、固定命令构造、固定／不支持目标、取消及不确定结果；不得使用真实个人应用作为升级回归夹具。前文目录查询保留原有 CLI 合同，不因此获得 CLI 软件包安装能力。

macOS 管理器行为、包内界面、辅助功能和安装影响须分别保留原生证据。本轮已在 Windows 11 x64 通过真实 COM 读取官方目录，并用 Computer Use 验证选择、筛选、完整冻结范围审阅与取消；没有对现有软件执行升级。Windows 纯 .NET 测试及交叉编译不能代替原生运行，以上只读验收也不证明安装器、提权、重启、ARM64 或完整辅助功能通过。当前检查与待验收项见 [SYNC.md](../../../SYNC.md)。
